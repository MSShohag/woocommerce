# WooCommerce Product Page Customizer

This repository contains PHP snippets to enhance the WooCommerce single product page.

## Features
* **Custom Layout:** Reorganizes the Add to Cart, Quantity selector, and adds a pulsing "Buy Now" button.
* **Estimated Delivery Timeline:** A visual shortcode `[estimated_delivery_box]` that dynamically displays delivery dates for Inside and Outside Dhaka.

## Usage
1. Copy the code from `woocommerce-custom-product-page.php`.
2. Paste it into your WordPress child theme's `functions.php` file, or use a plugin like Code Snippets.
3. Place the shortcode `[estimated_delivery_box]` anywhere on your product page to display the timeline widget.
